FILES
-----
hr_agent/
  indexing.py    - Builds vector index from policy.txt into storage/
  agent.py       - Core 4-step workflow (Retrieve → Check → Answer/Escalate)
  web.py         - Web server on Port 8050
  evaluation.py  - Scenario metrics calculator (Scenarios 1-6)
  run.bat        - One-click launcher (starts Ollama + web server)
  policy.txt     - Official HR policy document (ground truth)
  storage/       - Persisted LlamaIndex vector store
  static/        - Frontend (index.html, style.css, app.js)

HOW TO RUN
----------
1. Start Ollama:    ollama serve
2. Pull models:     ollama pull qwen2.5 && ollama pull nomic-embed-text
3. Build index:     python indexing.py
4. Test agent:      python agent.py
5. Run Web Portal:  python web.py   (opens http://127.0.0.1:8050)
6. Run Evaluation:  python evaluation.py
   Or just double-click: run.bat

ARCHITECTURE (4-Step Workflow)
------------------------------
  Employee Query
       ↓
  STEP 1: RETRIEVE  → Semantic search (nomic-embed-text, Top-2 chunks)
       ↓
  STEP 2: CHECK     → LLM triaging (ROUTINE vs ESCALATE)
       ↓
  STEP 3: ANSWER    → Grounded response via ChatOllama (qwen2.5)
       or
  STEP 4: ESCALATE  → Route to HR Specialist with ticket
